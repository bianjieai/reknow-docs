# 睿阁用户使用文档

> 本文档对应应用版本：v1.2.0

睿阁是一款企业级知识库智能体，帮助企业管理知识资产、构建智能体、实现团队协作与精准问答。睿阁提供灵犀版、企业版、旗舰版三个版本，部分高级功能（如自定义智能体、场景智能体、MCP 工具集成等）仅在特定版本可用，文档中会标注功能所属版本。

本目录是面向**最终用户**的使用文档。文档采用 [Diátaxis](https://diataxis.fr/) 框架组织，按用户意图分为四类：**入门**（学习上手）、**教程**（端到端任务）、**操作指南**（功能模块操作）、**参考**（查阅型资料），并辅以**概念解释**帮助理解底层机制。

---

## 应用功能全景

睿阁采用**左侧边栏 + 右侧内容区**布局（见 `getting-started/02-interface-overview.md`）：

- **左侧边栏**：知识库菜单、智能体菜单、团队菜单、新对话菜单、历史会话列表、用户信息区
- **右侧内容区**：根据选中菜单切换显示知识库列表、智能体列表、团队列表或对话页面

核心功能模块：

- **知识库管理**：创建文档库/FAQ 库，上传文档自动解析，配置解析引擎与分块策略
- **智能体管理**：使用内置智能体或创建自定义智能体（企业版+），配置提示词、模型、知识库与技能
- **团队协作**：创建团队、管理成员、共享知识库
- **对话问答**：选择智能体发起对话，支持多轮对话、附件上传、@提及
- **全局搜索**：Ctrl+K 快捷搜索对话与知识库内容
- **系统设置**：模型管理、解析引擎、向量数据库、存储引擎等配置

### 2. 路径与引用
- 文档之间的交叉引用使用**相对路径** markdown 链接（如 `[知识库管理](/zh/how-to/01-knowledge-base)`）。

### 3. 版本对齐
- README 头部标注"本文档对应应用版本 vX.Y.Z"。
- 每篇文档底部标注"最后更新 / 对应版本"。

### 4. 用语规范
- 睿阁是私有化部署的 Web 应用，不写安装指南，演示环境直接访问网页使用。
