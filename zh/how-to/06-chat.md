## 概述

对话是睿阁的核心交互方式。你通过对话向智能体提问，智能体结合知识库、网络搜索等能力为你提供精准回答。本文介绍如何新建对话、使用输入框功能、管理历史会话，以及@提及等进阶用法。

读完本文你将能够：

- 创建新对话并发送消息。
- 切换智能体、选择模型、上传图片和附件。
- 管理历史会话：置顶、重命名、清空、批量删除。
- 使用@提及引用知识库、文件和 Skill。

---

## 前置条件

- 已登录睿阁并进入主工作区。
- 系统中至少配置了一个可用的对话模型（管理员在[全局设置](/zh/reference/04-settings)中配置）。

## 操作步骤

### 1. 新对话页面

![新对话页面](/images/ht-06-new-chat.png)

点击左侧侧边栏的「新对话」菜单，进入新对话页面。

**欢迎语区域**：居中显示「你好，我是睿阁，让你的知识触手可及」。

**推荐问题区域**：
- 标题「你可以这样问我」，右侧有刷新按钮可重新获取推荐问题（加载中显示旋转图标）。
- 最多展示 8 个推荐问题卡片（按智能体设置的推荐问题数量展示），点击即可直接发送该问题；来源为 FAQ 的卡片带有「FAQ」标签，加载时以骨架屏占位。
- 推荐问题会根据当前选中的智能体、已选知识库、已选文件和已选 Skill 自动更新（相关选择变化后约 300ms 防抖重新获取）。

### 2. 输入框区域

![输入框区域](/images/ht-06-input.png)

输入框位于页面底部，支持以下功能：

**左侧控制栏**：

| 功能 | 说明 |
|------|------|
| 智能体切换 | 显示当前智能体名称（默认「智能推理」），点击展开智能体选择器 |
| 网络搜索开关 | 智能体启用时显示，控制是否在回答时检索互联网信息 |
| 图片上传 | 仅智能体支持图片时显示，支持 jpg/png/gif/webp，最多 5 张 |
| 附件上传 | 回形针图标，最多 5 个文件，支持拖拽上传，已有附件时显示数量角标 |
| @提及 | 引用知识库、文件或 Skill，详见[进阶用法](#提及) |

**右侧控制栏**：
- **模型选择器**：下拉选择对话模型，管理员可在此添加新模型。
- **发送/停止按钮**：输入框为空时灰色禁用，有内容时高亮显示，点击或按 Enter 发送，Shift+Enter 换行。消息流式生成过程中按钮变为「停止生成」，点击可立即中断流式输出；首包返回前重复点击发送或按 Enter 不会重复发送同一提问。

### 3. 选择智能体

![选择智能体](/images/ht-06-select-agent.png)

点击智能体切换按钮，展开智能体选择器面板：

- **顶部操作栏**：非普通成员显示「+ 管理」按钮跳转智能体列表；普通成员显示「浏览 查看」按钮。
- **智能体分组**：
  - 内置智能体：所有人可见。
  - 自定义智能体：显示所有未停用的自定义智能体。
- **智能体详情浮窗**：鼠标悬停某智能体时，右侧显示详情浮窗，包含：
  - 头像、名称、描述（无描述时显示「暂无描述」）
  - 状态标签：当前选中的智能体显示「当前」；未就绪时显示未就绪原因列表
  - 能力标签：运行模式（智能推理）、知识库能力（企业版固定显示「可访问全部知识库」）、MCP 能力（按配置显示「全部服务」「指定 N 个服务」等，未配置时不显示）、多轮对话（启用时显示）
  - 能力详情：网络搜索（开启 / 未配置 / 关闭）、图片上传（支持 / 不支持）
  - 设置按钮（企业创建者或企业管理员可见；智能体未就绪时显示跳转图标进入配置页面，已就绪时进入设置页面）

> 注意：「未就绪」状态的判定条件为缺少对话模型（未选择对话模型或模型不可用），或智能推理模式下启用知识库搜索但缺少重排模型。未就绪的智能体无法选择进行对话，管理员可点击设置按钮跳转配置页面。

### 4. 历史会话列表

左侧侧边栏「新对话」菜单下方是历史会话列表区域，顶部显示区域标题「我的对话」，按日期分组展示：

- **会话来源筛选器**：支持按来源筛选会话（Web / IM 渠道等），仅在存在多个来源时显示。
- **分组依据**：优先按会话更新时间分组，更新时间为空时按创建时间分组；空分组不展示，无任何会话时显示「暂无对话」。

| 分组 | 排序规则 |
|------|---------|
| 已置顶 | 按置顶时间降序 |
| 今天 | 按更新时间降序 |
| 昨天 | 按更新时间降序 |
| 近 7 天 | 按更新时间降序 |
| 近 30 天 | 按更新时间降序 |
| 近 1 年 | 按更新时间降序 |
| 更早 | 按更新时间降序 |

每个会话行显示标题（超长截断，最大 80 字符，由对话模型自动生成）。置顶会话显示图钉图标，当前激活的会话高亮显示。

### 5. 会话操作

点击会话行上的「…」图标打开操作菜单，可执行以下操作：

| 操作 | 说明 |
|------|------|
| 置顶/取消置顶 | 将会话固定到列表顶部或取消固定 |
| 修改标题 | 进入编辑模式（输入框自动聚焦并选中文本），标题最大 80 字符 |
| 清空消息 | 清除会话中的所有消息 |
| 批量管理 | 进入批量选择模式，勾选多个会话后批量删除 |
| 删除记录 | 删除单条会话（红色文字） |

菜单点击外部区域自动关闭。

**批量管理模式**：
1. 在会话行的「…」菜单中选择「批量管理」。
2. 每行左侧出现复选框，点击整行或复选框可切换选中状态。
3. 底部操作栏显示全选复选框、取消按钮和删除按钮（显示已选数量）。

### 6. 消息发送

![多轮对话](/images/ht-06-conversation.png)

- 按 **Enter** 发送消息。
- 按 **Shift+Enter** 换行。
- 输入框支持拖拽文件上传附件。

### 7. 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 接口返回结果中缺少会话 id | 显示错误提示「创建会话失败」 |
| 接口调用异常（如网络错误） | 显示错误提示「创建会话失败，请稍后重试」 |
| 会话创建成功但消息发送失败 | 会话已存在于侧边栏，可进入该会话手动重新发送 |

## 进阶用法

### @提及

在输入框中输入 `@` 触发提及选择器，可引用以下内容：

| 类型 | 说明 |
|------|------|
| 知识库 | 引用整个知识库，智能体将在该知识库范围内检索回答 |
| 文件 | 引用知识库中的特定文件（文件范围与知识库范围一致） |
| Skill | 引用特定的智能体技能 |

分组由智能体类型决定：Wiki 问答智能体不提供文件分组；企业版知识库范围固定为全部知识库。

@提及的内容会作为上下文传递给智能体，帮助其更精准地理解你的问题。

### 切换智能体后推荐问题的变化

切换智能体后，推荐问题区域会自动更新为该智能体关联的问题。推荐问题还会根据已选的知识库、文件和 Skill 动态调整。

## 常见问题

### Q1：提示「创建会话失败」怎么办？

如果提示「创建会话失败」，说明接口未正常返回会话信息；如果提示「创建会话失败，请稍后重试」，通常是网络等异常，稍后重新发送即可。若会话已创建但消息发送失败，会话会保留在侧边栏，可进入该会话手动重新发送。

### Q2：对话标题能修改吗？

可以。点击会话行上的「…」图标选择「修改标题」，进入编辑模式后输入框自动聚焦并选中文本，标题最大 80 字符。会话标题默认由对话模型根据对话内容自动生成。

### Q3：删除会话后还能找回吗？

删除会话是不可恢复的操作，删除后该会话及其所有消息将永久丢失。删除前请仔细核对。

### Q4：为什么有些智能体无法选择？

如果智能体显示「未就绪」状态，说明该智能体缺少必要配置（未选择对话模型或模型不可用，或智能推理模式下启用知识库搜索但未选择重排模型）。请联系管理员在智能体设置中补充配置。

### Q5：推荐问题为什么不显示？

推荐问题依赖智能体配置。如果当前智能体未设置推荐问题，或智能体未就绪，推荐问题区域将不会显示。
