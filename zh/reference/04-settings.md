## 概述

全局设置集中管理睿阁的账户偏好、企业信息、AI 模型和基础设施配置。通过用户信息区的「全部设置」按钮进入，弹窗尺寸 1080×780px，左侧导航栏 + 右侧内容区布局。

本文按分组介绍各设置页面的功能和操作方式。

---

## 前置条件

- 已登录睿阁并进入主工作区。
- 部分设置项需要管理员或所有者权限。

| 设置项 | 控件 | 说明 |

| 开启记忆功能 | 开关 | 开启后系统记录对话历史并在后续对话中自动回忆，仅 Neo4j 可用时可操作 |

### 用户信息

![用户信息](/images/ref-04-userinfo.png)

只读展示以下账户信息：
- 用户 ID（唯一标识）
- 用户名（登录用户名）
- 邮箱（注册邮箱）
- 注册时间（YYYY/MM/DD HH:mm 格式）

企业 SSO（单点登录）托管账号（钉钉/飞书）额外显示：
- 邮箱位置显示脱敏占位符 `--`，悬浮提示「第三方企业平台托管账号」。
- 新增「账号来源」行，显示「当前账号由企业第三方单点登录托管」及平台标签（钉钉/飞书）。

### 修改密码

![修改密码](/images/gs-01-change-password.png)

> 注意：修改密码后当前登录状态将失效，提交成功后系统会自动退出并跳转到登录页（邮箱已预填），需要使用新密码重新登录。

企业 SSO（单点登录）托管账号（钉钉/飞书）进入本页面时：
- 页面顶部显示黄色警告条「企业 SSO 账号无法修改密码」，不显示「登录状态失效」提醒。
- 整个表单置灰不可编辑，全部输入框禁用，提交同样被拒绝并提示「企业 SSO 账号无法修改密码」。

| 字段 | 说明 |
|------|------|
| 当前密码 | 必填 |
| 新密码 | 必填，8-32 个字符，包含字母和数字，不能与当前密码相同 |
| 确认新密码 | 必填，需与新密码一致 |

**校验规则**：

| 校验项 | 错误提示 |
|--------|---------|
| 未输入当前密码 | 「请输入密码」 |
| 未输入新密码 | 「请输入密码」 |
| 新密码少于 8 位 | 「密码至少8个字符」 |
| 新密码超过 32 位 | 「密码不能超过32个字符」 |
| 新密码无字母 | 「密码必须包含字母」 |
| 新密码无数字 | 「密码必须包含数字」 |
| 新密码与当前密码相同 | 「新密码不能与当前密码相同」 |
| 确认密码与新密码不一致 | 「两次输入的密码不一致」 |

### 管理员管理

**角色权限说明**：

| 角色 | 管理管理员 | 修改企业配置 | 配置模型/向量库 | 创建编辑知识库和智能体 | 查看企业内容 |
|------|:---:|:---:|:---:|:---:|:---:|
| 所有者（Owner） | ✅ | ✅ | ✅ | ✅ | ✅ |
| 管理员（Admin） | ❌ | ❌ | ✅ | ✅ | ✅ |

**邀请管理员**（仅所有者）：
1. 点击「邀请管理员」按钮（弹窗 420px 宽，两步流程）。
2. 搜索用户名或邮箱（输入至少 2 个字符触发远程搜索）。
3. 选择用户后进入确认步骤，点击「发送」发出邀请（邀请角色固定为管理员）。
4. 被邀请人在站内接受后成为管理员。

**审计日志**：点击「审计日志」按钮打开右侧抽屉（880px 宽），查看操作审计记录（成员变更与访问拒绝事件），按时间倒序展示。一分钟内的重复拒绝会自动去重，点击记录可展开查看详情。

**管理员列表**：支持按姓名或邮箱搜索成员、移除管理员（仅所有者，不可移除自己）。SSO（单点登录）成员姓名后显示账号来源徽章（「钉钉」或「飞书」），邮箱位置显示脱敏占位符 `--`（悬浮提示「第三方企业平台托管账号」）。

**待接受邀请列表**：展示已发出的邀请及状态（待接受、已接受、已拒绝、已撤销、已过期），仅「待接受」状态的邀请可撤销。发出后等待对方在站内确认，逾期未响应将自动过期。SSO（单点登录）成员姓名后显示账号来源徽章（「钉钉」或「飞书」），邮箱位置显示脱敏占位符 `--`（悬浮提示「第三方企业平台托管账号」）。

### 成员管理

![成员管理](/images/ref-04-members.png)

管理普通成员账号状态，支持查看、禁用和启用，并支持从组织架构同步成员。

**普通成员列表**：
- 搜索框：按用户名或邮箱搜索。
- 状态筛选：全部状态 / 正常 / 已禁用。
- 成员列：姓名 + 邮箱。SSO（单点登录）成员姓名后显示账号来源徽章（「钉钉」或「飞书」，与企业配置的 SSO 主平台一致），邮箱位置显示脱敏占位符 `--`（悬浮提示「第三方企业平台托管账号」）；普通邮箱账号仍显示真实邮箱。
- 注册时间：YYYY/MM/DD HH:mm 格式。
- 状态列（胶囊标签）：「正常」（带呼吸小圆点）/「已禁用」。
- 操作列：「禁用」/「启用」按钮，均带二次确认气泡。
- 分页：显示总条数、页码导航、页码跳转、每页条数（10/20/50/100）。

**从组织架构同步**：点击「从组织架构同步」按钮打开「组织架构成员同步」弹窗。按钮仅在企业启用 SSO（单点登录）且当前用户为企业所有者或企业管理员时显示。

**组织架构成员同步弹窗**（680px 宽）：
- 顶部平台条：显示数据源平台（钉钉/飞书）及「单批次最多支持同步 200 人」。
- 左栏「组织部门」（部门树）：点击部门加载子部门与直属成员；无数据时显示「暂无部门数据」。
- 右栏「{部门名} - 直属成员」：标题下方显示「已加载 N 人」；未选择部门时显示占位提示「请在左侧选择部门以查看直属成员」。工具栏提供「全选未同步成员」勾选框和搜索框（按成员名称搜索）。
- 成员表（最高 340px，可滚动）：列为勾选框 / 姓名 / 状态。「已同步」绿色标签（不可勾选）、「未同步」蓝色标签（可勾选）；触底自动加载更多；该部门下暂无直属成员时显示空态「该部门下暂无直属成员」。
- 底部：「已勾选 N 人」计数徽标（勾选超过 200 人时显示超限警告「（单批次最多支持同步 200 人）」）+「取消」按钮 +「开始同步」按钮（0 人勾选时禁用，提交中显示「正在同步中...」）。

**成员同步结果弹窗**（640px 宽）：
- 4 张计数卡片：总计处理 / 成功开通 / 已存在跳过 / 开通失败。
- 失败原因详情（仅存在开通失败人员时显示）：人员名称 / 失败原因 两列表格（最高 240px，可滚动）。
- 「完成」按钮仅关闭弹窗，成员列表由同步流程自动刷新。

### 消息管理

- **启用消息索引**开关：默认关闭，切换后自动保存（约 500ms 防抖）。开启后新对话消息自动索引到知识库，支持向量搜索。
- **Embedding 模型**：仅启用消息索引时显示，选择用于消息向量化的模型。已有索引消息时锁定不可更换，显示警告「已有消息被索引，Embedding 模型不可修改（修改需清空索引数据）」。
- **索引统计**：显示已索引消息数量。未配置时显示空状态「消息索引未配置，启用并选择 Embedding 模型后，对话消息将自动向量化索引」。

## 模型设置

### 模型管理

![模型管理](/images/ref-04-models.png)

按类型分 Tab 展示：全部 / 对话 / Embedding / ReRank / 视觉 / 语音。

**模型卡片**：显示模型名称、类型徽章、供应商、操作菜单（编辑/复制/删除）。内置模型显示锁定图标，删除仅非内置模型可用。

**添加/编辑模型**：

| 区域 | 配置项 |
|------|--------|
| 基本信息 | 模型类型（chat/embedding/rerank/vllm/asr）、来源（local Ollama / remote API） |
| Remote API 配置 | 服务商选择、模型名称、显示名称、Base URL、API Key、自定义请求头；选择腾讯云 LKEAP 且模型类型为 Rerank 时额外填写 Secret ID、Secret Key、地域 |
| 高级选项 | 向量维度（embedding，128-4096，带「检测维度」按钮）、维度覆盖开关（embedding）、支持视觉/多模态（chat）、思维链控制（chat 远程 API）、后台并发上限（0 表示使用全局默认） |

**支持的服务商**：OpenAI、Azure OpenAI、阿里云 DashScope、智谱 BigModel、OpenRouter、Requesty、Google Gemini、硅基流动 SiliconFlow、Jina、火山引擎 Volcengine、DeepSeek、腾讯混元 Hunyuan、腾讯云 LKEAP、MiniMax、小米 MiMo、GPUStack、魔搭 ModelScope、七牛云 Qiniu、月之暗面 Moonshot、百度千帆 Baidu Cloud、LongCat AI、NVIDIA、Novita AI、自定义（OpenAI 兼容接口）等。

**思维链控制**（仅 chat 远程 API）决定智能体「思考模式」开/关时如何写入 API 请求：

| 选项 | 说明与适用服务商 |
|------|----------------|
| 不写入思考参数 | 智能体「思考模式」开关不生效 |
| chat_template_kwargs | 自定义 OpenAI 兼容、NVIDIA NIM、vLLM / 本地 Qwen 部署 |
| enable_thinking | 阿里云 DashScope（qwen3、qwen-plus、qwen-max、qwen-turbo） |
| thinking.type | 火山引擎 Ark；腾讯云 LKEAP（DeepSeek V3 等） |

> 提示：添加远程模型时可点击「测试连接」验证 API 连通性。

### Ollama

![Ollama](/images/ref-04-ollama.png)

管理本地 Ollama 服务：
- **服务状态**：自动检测（检测中/可用/不可用/未检测），可点击「重新检测」。
- **服务地址**：默认 http://localhost:11434，如需修改请在 .env 配置文件中设置。
- **下载新模型**：输入模型名称（如 qwen2.5:0.5b）下载。仅连接成功时显示。
- **已下载的模型**：展示已安装的模型列表（名称、大小、修改时间）。仅连接成功时显示。

## 常见问题

### Q1：普通成员能看到哪些设置？

普通成员只能看到「账户」分组下的常规设置、用户信息和修改密码。企业信息、管理员管理、消息管理仅企业所有者可见；成员管理、模型和数据扩展设置仅企业管理员及以上可见。

### Q2：添加模型时报错「SSRF validation failed」怎么办？

ReKnow-Core 内置 SSRF 安全校验。需要在 engine 容器的环境变量中添加 `SSRF_WHITELIST_EXTRA`，将模型服务的域名加入白名单（逗号分隔）。修改后需重启 engine 容器生效。详见 [常见问题](/zh/faq)。

### Q3：Ollama 服务检测不到怎么办？

确认 Ollama 已在本地运行。默认服务地址为 http://localhost:11434，如需修改请在 .env 配置文件中设置 DOCREADER_ADDR 等环境变量后重启服务。

### Q4：向量数据库创建后能更换引擎类型吗？

不能。创建后引擎类型和连接配置不可修改，如需更换请删除后重新创建。

### Q5：存储实例删除失败怎么办？

删除前需满足以下条件：非环境变量来源、非工作区默认实例、无知识库绑定、无活跃资源关联、非旧版配置迁移的别名实例。检查不满足的条件后逐一解除关联。
