## 概述

睿阁是一款私有化部署的 Web 应用，通过浏览器访问即可使用，无需安装任何客户端。本篇介绍如何获取访问地址、完成登录或注册账号，以及如何管理你的账户信息。

读完本篇后，你将能够顺利登录睿阁并管理自己的账号与会话。

## 前置条件

- 管理员已完成睿阁的私有化部署
- 你已拥有睿阁账号（通过管理员创建或自行注册）
- 你已获取睿阁的访问地址（由管理员提供）
- 电脑已安装主流浏览器（推荐 Chrome、Edge）

## 操作步骤

### 1. 获取访问地址

联系你的系统管理员，获取睿阁的访问地址。地址格式通常为：

- 内网部署：`http://<服务器IP>:<端口>` 或 `https://<域名>`
- 例如：`http://192.168.1.100:8080` 或 `https://reknow.yourcompany.com`

> 提示：首次访问时，浏览器可能会提示"连接不安全"（HTTP 协议），这是因为内网部署未配置 SSL 证书。点击"高级 → 继续访问"即可，不影响正常使用。

### 2. 打开浏览器

使用 Chrome、Edge 等主流浏览器，在地址栏输入管理员提供的访问地址，按回车键打开。

你将看到睿阁的登录页面，页面中央显示登录表单卡片，底部显示产品功能标签（多模态解析、混合搜索引擎、RAG 问答）。

> 注意：如果系统 License 已失效，页面顶部会显示红色警告提示，所有操作按钮均被禁用。请联系管理员处理 License 问题。

### 3. 输入邮箱和密码登录

在登录页面中：

1. 输入你的**邮箱地址**
2. 输入对应的**密码**
3. 点击「登录」按钮或按 Enter 键

登录按钮点击后会显示加载状态（文案变为「登录中...」），请求完成后根据结果显示：

| 结果 | 表现 |
|------|------|
| 登录成功 | 自动跳转到主页面（知识库列表） |
| 登录失败 | 显示 Toast 错误提示：「登录错误，请检查邮箱或密码」或「登录错误，请稍后重试」 |

**表单校验规则**：

| 字段 | 校验规则 | 错误提示 |
|------|---------|---------|
| 邮箱 | 不能为空 | 「请输入邮箱地址」 |
| 邮箱 | 格式正确 | 「请输入正确的邮箱格式」 |
| 密码 | 不能为空 | 「请输入密码」 |
| 密码 | 至少 8 个字符 | 「密码至少8个字符」 |
| 密码 | 不超过 32 个字符 | 「密码不能超过32个字符」 |
| 密码 | 必须包含字母 | 「密码必须包含字母」 |
| 密码 | 必须包含数字 | 「密码必须包含数字」 |

### 4. 登录后跳转逻辑

登录成功后，系统根据你的角色决定跳转目标：

| 用户角色 | 首次登录 | 非首次登录 |
|---------|---------|-----------|
| 企业所有者 | 跳转到协议签署页（需签署后才能进入系统） | 跳转到主页面（知识库列表） |
| 其他用户 | 跳转到主页面（知识库列表） | 跳转到主页面（知识库列表） |

> 提示：首次进入主页面时，系统会自动弹出**新手引导**，通过聚光灯 + 遮罩 + 浮动卡片的方式，带你快速了解核心功能区域。你可以跟随引导完成初始了解，也可以点击"跳过"稍后通过用户菜单重新打开。

## 注册新账号

如果你还没有睿阁账号，可以在登录页面自行注册。

1. 在登录页面底部，点击「创建账户」按钮
2. 页面切换到注册界面，依次填写：
   - **用户名**（placeholder：输入用户名）
   - **邮箱地址**（placeholder：输入邮箱地址）
   - **密码**（placeholder：输入密码（8-32个字符，包含字母和数字））
   - **确认密码**（placeholder：再次输入密码）
3. 点击「注册」按钮或按 Enter 键

**注册表单校验规则**：

| 字段 | 校验规则 | 错误提示 |
|------|---------|---------|
| 用户名 | 不能为空 | 「请输入用户名」 |
| 用户名 | 至少 2 个字符 | 「用户名至少2个字符」 |
| 用户名 | 不超过 20 个字符 | 「用户名不能超过20个字符」 |
| 用户名 | 只能包含字母、数字、下划线和中文 | 「用户名只能包含字母、数字、下划线和中文字符」 |
| 邮箱 | 不能为空 | 「请输入邮箱地址」 |
| 邮箱 | 格式正确 | 「请输入正确的邮箱格式」 |
| 密码 | 同登录密码规则 | 同登录密码错误提示 |
| 确认密码 | 不能为空 | 「请确认密码」 |
| 确认密码 | 与密码一致 | 「两次输入的密码不一致」 |

| 结果 | 表现 |
|------|------|
| 注册成功 | Toast 提示「注册成功，请登录」，自动切回登录界面并预填邮箱 |
| 注册失败 | Toast 提示「注册失败」或「注册错误，请稍后重试」 |

注册完成后，使用刚注册的邮箱和密码登录即可。

## 企业所有者协议签署

企业所有者首次登录时，需要阅读并签署《产品服务协议》才能使用系统。签署完成后，后续登录不再显示此页面。

### 触发条件

- 仅企业所有者角色首次登录时自动触发
- 企业所有者访问任何页面时，若未签署协议会被自动重定向到此页面
- 非企业所有者不会看到此页面

### 签署步骤

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 首次登录后自动跳转到协议签署页 | 页面加载协议内容，顶部显示睿阁 Logo 和退出登录按钮 |
| 2 | 向下滚动阅读协议内容 | 滚动到底部后，底部签署栏显示 |
| 3 | 勾选「我已阅读并同意《产品服务协议》」复选框 | 勾选后「同意并继续」按钮变为可点击状态 |
| 4 | 点击「同意并继续」按钮 | 发送签署请求 |

| 结果 | 表现 |
|------|------|
| 签署成功 | Toast 提示「协议签署成功，即将进入系统」，自动跳转到主页面 |
| 签署失败 | Toast 提示「签署失败，请稍后重试」或「网络连接失败，请检查网络后重试」 |

**拒绝签署**：点击「暂不同意并退出」，弹出确认对话框（「确认退出登录？」「退出后将返回登录页面。签署《产品服务协议》后方可使用系统功能，您可随时重新登录完成签署。」），确认后退出登录并跳转到登录页。

## 用户信息区

在左侧边栏底部，显示当前登录用户的信息区。点击用户信息区域可展开/折叠详细信息。

展开后显示以下内容：

| 项目 | 说明 |
| --- | --- |
| 头像 | 当前用户的头像 |
| 名称 | 当前用户的显示名称 |
| 新手引导 | 点击可重新打开新手引导 |
| 工作空间 | 当前所属工作空间的名称和所有者信息 |
| 全部设置 | 点击打开设置弹窗，可管理账户、企业、模型等配置 |
| 退出 | 点击退出当前登录，返回登录页 |

## 修改密码

1. 点击左侧边栏底部的用户信息区
2. 点击「全部设置」按钮
3. 在设置弹窗左侧导航中选择「账户 → 修改密码」
4. 输入当前密码、新密码、确认新密码
5. 点击「修改密码」按钮或按 Enter 键

> 注意：修改密码后，当前登录状态将失效，系统会自动退出并跳转到登录页（邮箱已预填），需要使用新密码重新登录。

**密码校验规则**：

| 字段 | 校验规则 | 错误提示 |
|------|---------|---------|
| 当前密码 | 不能为空 | 「请输入密码」 |
| 新密码 | 不能为空 | 「请输入密码」 |
| 新密码 | 至少 8 个字符 | 「密码至少8个字符」 |
| 新密码 | 不超过 32 个字符 | 「密码不能超过32个字符」 |
| 新密码 | 必须包含字母 | 「密码必须包含字母」 |
| 新密码 | 必须包含数字 | 「密码必须包含数字」 |
| 新密码 | 不能与当前密码相同 | 「新密码不能与当前密码相同」 |
| 确认密码 | 不能为空 | 「请确认密码」 |
| 确认密码 | 与新密码一致 | 「两次输入的密码不一致」 |

密码规则（适用于登录、注册、修改密码）：

| 规则 | 说明 |
|------|------|
| 长度 | 8~32 位 |
| 必须包含字母 | 至少一个英文字母（a-z 或 A-Z） |
| 必须包含数字 | 至少一个数字（0-9） |

## 退出登录

1. 点击左侧边栏底部的用户信息区
2. 点击「退出」按钮
3. 系统将清除登录状态并返回登录页

> 提示：退出登录不会删除你的知识库、对话记录等数据。再次登录后可继续使用。

## 常见问题

### Q1：打开访问地址后显示空白页或无法连接怎么办？

可能原因与处理方式：

- **地址输入错误**：确认访问地址是否正确，注意端口号
- **服务器未启动**：联系管理员确认睿阁服务是否正常运行
- **网络不通**：确认你的电脑与服务器在同一网络，或 VPN 已连接
- **防火墙拦截**：确认服务器防火墙已开放对应端口

### Q2：登录时提示"登录错误，请检查邮箱或密码"怎么办？

- 确认邮箱和密码是否输入正确，注意大小写
- 如果忘记密码，请联系管理员重置密码
- 确认 Caps Lock 键是否误开启

### Q3：登录后页面一直加载中怎么办？

- 尝试刷新页面（F5）
- 清除浏览器缓存后重新访问
- 检查网络连接是否稳定
- 如果问题持续，联系管理员检查服务器状态

### Q4：如何修改用户名或邮箱？

用户名和邮箱为系统只读信息，无法自行修改。如需变更，请联系管理员在后台进行修改。

### Q5：密码修改后多久生效？

密码修改后立即生效。当前会话会被强制退出，需要使用新密码重新登录。

### Q6：注册时提示邮箱已被使用怎么办？

说明该邮箱已注册过账号。请直接使用该邮箱登录，或使用其他邮箱注册。如果忘记密码，可在登录页联系管理员重置。

### Q7：登录后提示需要签署协议但无法签署怎么办？

协议签署功能仅限企业所有者。如果遇到签署页面加载失败，请点击「重新加载」重试。如问题持续，请联系管理员检查服务状态。
